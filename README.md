# Northwind E-Commerce Data Validation & Analysis 📊

## 📌 Project Overview
This project presents an end-to-end analytical study of the classic **Northwind Traders** database. Using **PostgreSQL** for deep-dive exploratory data analysis and **Power BI** for executive reporting, the analysis focuses on evaluating business performance across sales trends, customer behavior, product health, and employee sales impact.

---

## 🛠️ Tools & Technologies Used
* **Database & Querying 🗄️:** PostgreSQL, DBeaver
* **Data Visualization 📈:** Microsoft Power BI
* **Analytics Concepts 🧠:** Complex Joins, Aggregations, Window Functions (Ranking, Running Totals, Lag), DAX Measures, Time-Intelligence Modeling

---

## 🔍 Key Analysis & Business Focus Areas
The repository contains 32 dedicated SQL queries structured across five business domains:

1. **Revenue & Category Performance 🏷️:** Assessed category revenue contributions, discount impacts, and top-earning segments.
2. **Customer Segmentation & Value 👥:** Analyzed Average Order Value (AOV), Customer Lifetime Value (CLV), multi-year repeat buyers, and Pareto's 80/20 rule distribution.
3. **Product Intelligence 📦:** Identified top-selling products, category benchmarks, inactive items, and products experiencing year-over-year declines.
4. **Sales Rep Productivity 👔:** Evaluated order counts, revenue per employee, and individual average order values.
5. **Business Performance Trends 📅:** Computed monthly revenue trajectories, running totals, and month-over-month (MoM) and year-over-year (YoY) growth rates.
